# Contributing

Read docs/ADD_APP.md. Submit one YAML registration per application and provide real public release
assets, source/licence information and honest device test results. Respect redistribution rights.
Disclose material AI assistance and review/test all submitted work. No piracy, DRM bypass or
firmware/system partition modifications. Maintain stable app IDs and increasing package versions.
Run the README checks before submitting a pull request. Keep changes close to upstream.
